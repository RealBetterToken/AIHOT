Target style: native Russian from a developer's technical blog, like a well-edited Habr post. Use natural verb-led Russian, correct cases and agreement, and normal technical collocations. Avoid Chinese sentence order, inflated official language and long chains of verbal nouns. Keep the author's voice, first-person perspective, and statement or question form. Coding agent = ИИ-агент для разработки; never call it an интеллект or программист-интеллект. Prompt = промпт (not necessarily a системный промпт), pull request = пул-реквест or PR, backlog = бэклог, rollback = откат. Deploy gate is a release control mechanism, not an aviation or physical barrier; pre-flight checks are проверки перед развёртыванием. Translate checkout in a store as оформление заказа, not проверка. Skill/Hook as named coding-tool features, tool names, API, CLI, SDK, IDE, MCP and RAG keep their original spelling. Prefer concise natural titles without dropping technical facts. Do not embellish an ordinary prompt with words such as clear, system or carefully crafted unless present in the source.
